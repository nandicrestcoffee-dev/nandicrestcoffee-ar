
# Nandi Crest Coffee — Arabic Edition (`nandicrestcoffee-ar`)

النسخة العربية الرسمية لمبادرة **Nandi Crest Coffee** لقهوة الأرابيكا الكينية عالية الارتفاع من مرتفعات ناندي ونيروبي.

## الروابط الأساسية
- **النسخة العربية (GitHub Pages):** https://nandicrestcoffee-dev.github.io/nandicrestcoffee-ar/
- **الموقع الرئيسي (English):** https://nandicrestcoffee-dev.github.io/
- **المدونة:** https://nandicrestcoffee.blogspot.com/?m=1
- **البريد الإلكتروني للمكتب الاستراتيجي:** nandicrestcoffee@gmail.com

## المواصفات التقنية
- **اتجاه النص:** من اليمين إلى اليسار (`dir="rtl"`, `lang="ar"`).
- **الخط:** `Cairo` عبر Google Fonts.
- **الملف الرئيسي:** `index.html` (صفحة تعريفية متكاملة موجهة للمستوردين والمحامص وشركاء التوريد).

---

### Technical Overview
Arabic language edition of **Nandi Crest Coffee** built for static hosting on GitHub Pages with full RTL layout support (`lang="ar" dir="rtl"`), linking back to the main site and blog.
